 Light Lab

Light Lab is a minimalist, responsive photography portfolio showcasing the interplay between natural light, and personal style.

 Live Demo
View the project live here:  
**[https://moseee6.github.io/Light-Lab/](https://moseee6.github.io/Light-Lab/)**

 Built With
* **HTML5** – Structured for semantic clarity and SEO.
* **CSS3** – Custom styling featuring a dark-mode aesthetic and smooth transitions.
* **Git/GitHub** – Version control and project hosting.
